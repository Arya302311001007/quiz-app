# Quiz App 🎯

A full-stack Quiz Application built using modern web technologies.  
This project allows users to attempt quizzes, view scores, and track performance in a simple and user-friendly way.

---

## 🚀 Features

- 📝 Multiple choice quiz questions
- ⏱️ Timer-based quiz submission
- 📊 Score calculation and display
- 🏆 Leaderboard (optional)
- 🔐 Simple and clean UI
- 🌐 REST API integration

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
git clone https://github.com/<your-username>/quiz-app.git
cd quiz-app
2️⃣ Frontend Setup
cd client
npm install
npm start
Frontend runs on:
http://localhost:3000

3️⃣ Backend Setup
cd server
npm install
node index.js
Backend runs on:
http://localhost:5000

📌 How It Works
User opens the quiz application

Quiz questions are loaded dynamically

User selects answers within the given time

Score is calculated and displayed

Results can be stored and viewed later
